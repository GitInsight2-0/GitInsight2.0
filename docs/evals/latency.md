# 판단 LLM 지연 측정

`uv run python scripts/llm_latency.py --n 20`이 아래 표에 한 줄씩 추가합니다.
첫 호출(예열)은 통계에서 뺍니다. 단위는 밀리초, 비용은 호출 1회 평균(USD)입니다.
판단 제한 시간(`JUDGE_TIMEOUT_S`, 기본 2.5초)은 이 표의 상위 95% 값을 보고 정합니다.

| 측정 시각(UTC) | 모델 | reasoning_effort | 호출 수 | 중앙값 | 상위 95% | 최대 | 실패 | 평균 비용 |
|---|---|---|---|---|---|---|---|---|
